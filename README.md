ConvertTest (Tuning Simulator)
Un program simplu în C# care simulează adăugarea unei turbine la motorul unei mașini pentru a crește puterea (HP).

Ce face programul:
Interacțiune: Cere utilizatorului să introducă numărul de cai putere (HP) pe care îi are mașina în varianta stock.

Conversie: Utilizează Convert.ToInt32 pentru a transforma input-ul de la tastatură într-un număr întreg.

Calcul Tuning: Adaugă automat un spor de 50 HP (simulând instalarea unei turbine).

Rezultat: Afișează puterea finală pe care o va avea mașina după modificare.

Concepte C# aplicate:
Conversia tipurilor de date: Trecerea de la string (text) la int (număr).

Operatori aritmetici: Adunarea valorilor numerice.

Concatenare: Combinarea textului cu variabile în Console.WriteLine.

Cum se rulează:
Rulează comanda dotnet run.

Introdu puterea mașinii tale și vezi rezultatul după tuning!
